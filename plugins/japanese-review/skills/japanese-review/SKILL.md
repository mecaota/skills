# 日本語文書のレビュー (japanese-review)

日本語の文書を書き終えたら、次の順でレビューを依頼し、指摘を確認して反映する。

## 前提の確認

このプラグインは、外部のツールを同梱も宣言もしない(プラグインの依存では宣言できないため)。レビューを始める前に、使える手段を確認する。

- Antigravity: `gemini` MCP の `ask` ツールが使えるか(ToolSearch で `mcp__gemini__ask` を探す)。
- gemini-api: Bash で `command -v gemini-api` が通るか。
- どちらも使えない手段は飛ばして次のレビュアーへ進み、最終報告で飛ばした理由を伝える。両方とも使えなければ、セルフレビューだけを行う。

## レビュアーの優先順位

Antigravity と gemini-api(APIキー)はレートリミットの枠が別なので、片方が使えなくてももう片方を試す。gemini-api は応答が遅いことが多いため、Antigravity を優先する。

1. **Antigravity**: `gemini` MCP の `ask` ツール(Antigravity CLI `agy` 経由)を使う。
   - `model` には `gemini-3.8-flash-high` を指定する。既定モデルは使えないことがある。
   - レビュー対象の本文はプロンプトに直接貼る。ファイルを読ませようとすると、ヘッドレスのためコマンド実行が拒否されて回答が得られない。プロンプトには「ファイルの読み込みやコマンド実行はしない」と明記する。
2. **gemini-api**: Antigravity がレートリミット・混雑・認証エラー・接続エラー・極端な遅延で使えないときに使う。
   - Bash で `gemini-api generate "<プロンプト>" --stream=false --output-format json -m gemini-3.8-flash` を実行する。
   - 出力 JSON の `steps` のうち `type` が `model_output` のものの `content[].text` を本文として読む(`--jq` で絞ってもよい)。
   - レビュー対象の本文はプロンプトに直接貼る。
   - サンドボックス内では TLS 証明書の検証に失敗する(`x509: OSStatus -26276`)ため、最初からサンドボックス外(`dangerouslyDisableSandbox: true`)で実行する。サンドボックスの内外で `$TMPDIR` が異なるので、一時ファイルを渡すときは絶対パスを使う。
   - キーはキーチェーンに保存済みで、初回はアクセス許可のダイアログが出ることがある。
   - レートリミット(429)・混雑(503)・認証エラー(終了コード3)・接続エラー・極端な遅延のときは次へ進む。
3. **セルフレビュー**: gemini-api も使えないときは、自分(Claude)が次の観点でレビューし、修正を反映する。
   - 誤字脱字
   - 敬体・常体の統一
   - 主語と述語の対応
   - 曖昧な表現
   - 事実との整合

## レビュー依頼のプロンプト

次を含める。

- 文書の種類と読み手(例: PRの Description、開発チーム向け)
- レビュー観点(誤字脱字・敬体常体の統一・主語述語の対応・曖昧な表現・読みやすさ)
- 「指摘は箇所と修正案をセットで返す」「ファイルの読み込みやコマンド実行はしない」
- 本文(そのまま貼る)

## 進め方

- **並列に回す**: Antigravity と gemini-api は応答が極端に遅いことがある。バックグラウンド(Bash の `run_in_background` やサブエージェント)で投げ、結果を待たずにセルフレビューや次の作業を進める。
- **遅れて届いた結果も必ず読む**: 届いたら中身を読み、妥当な指摘は反映する。PR 本文や Notion など書き込みを先に済ませていた場合は、差分で直す。
- **指摘は文法と事実で扱いを分ける**:
  - 誤字・語法・表現など文法関連の指摘は、好みで見送らずに反映する。Gemini は事実を誤ることがあるが、日本語は上手い。
  - 数値・ファイル名・原因・挙動など事実を変える指摘は、元の事実と照らして確認し、食い違えば拒否する。
- サブエージェントに委譲するときは、この優先順位、本文の直貼り、並列実行、文法と事実の線引きを指示に書く。

## 最終報告

どのレビュアーを使ったかを一言添える。Antigravity や gemini-api を飛ばした場合は、その理由(レートリミット・遅延など)も伝える。
